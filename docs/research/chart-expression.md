# 用量图表表达对标与本轮选择

调研日期：2026-09-26。以下功能事实取自项目自己的 GitHub README。

| 项目 | 图表与交互做法 | 本项目借鉴 |
|---|---|---|
| [Token Use](https://github.com/russmckendrick/tokenuse) | 总览放每日成本与调用活动；另有滚动 24 小时用量页。 | 最近活动使用真正的滚动时间桶，与日历日趋势分开。 |
| [Tokscale](https://github.com/junhoyeo/tokscale) | Overview 可在按日/按小时图间切换；另有热力图、模型、会话等视角。 | 把时间范围切换放在图表旁，保留现有热力图页。 |
| [mtok](https://github.com/kerem-kaynak/mtok) | 仪表板包含每日柱图、来源与模型占比；可一键切换 Token 与金额。 | 同一张趋势图可切 Token/金额，让数据回答不同问题。 |
| [Token Monitor](https://github.com/Javis603/token-monitor) | 趋势可按工具或模型堆叠，并提供活动热力图与时段范围。 | 用稳定颜色堆叠 Agent，图例只出现本范围内有数据的 Agent。 |
| [ccdash](https://github.com/jedarden/ccdash) | 将短时用量速率与会话状态放在同一终端面板。 | 顶部简短展示近 60 分钟用量、平均速率和用量最多的 Agent；“最近记录”只表示观测到的日志。 |

## 本轮界面决定

- 在现有 Token 用量页顶部用两行显示近 60 分钟本机用量和最紧张的真实订阅额度；今日/周/月合并为一行。
- 趋势图切换滚动 **24 小时 / 近 14 天**与 **Token / 金额**，颜色按 Agent 固定；点击柱条看该时段构成。
- 24 小时图从原始记录生成连续小时桶；现有“按小时分布”是近 30 天作息统计，口径不同。
- 图表始终使用短标签，窄终端保留柱条与必要的时间刻度。现有来源异常只保留简短错误提示。
