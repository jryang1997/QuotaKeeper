## 真机暴露的问题（本轮已修）

1. 卡片标题两处重复（面板头 + 卡内）→ 模块支持 `bare`，自带标题的卡不再渲染面板头。
2. 用量页四张摘要砖高度虚高、卡内滚动条 → 改 1 行高 + 卡内单行布局；速度榜压成单行。
3. 卡内滚动条比正文还抢眼 → 模块体滚动条细一号（6px）。
4. 额度带缺"未接入"行 → 补齐并弱化。
5. 计划名重复（`OPENCODE GO` + `OPENCODE GO` 徽章）→ 同名不显示徽章；长徽章省略号。
6. 设置页旧的 sticky 外观卡 → 删除。
7. 设置页大标题与工具栏标题重复 → 去掉页内 h1。
8. `⋯` 菜单缺"套餐详情" → 按静态模型表判断可用性。
9. CDP 取图工具只连 `::1`，本机 WebView2 绑了 `127.0.0.1` → 双栈兜底。

## 第二轮（2026-10-04）

Jerry 截图的"顶部叠字"已经定位并修掉：吸顶工具栏原先用 `top:-18px` 上移，`.main` 的 18px 上内边距把 sticky 夹住，滚动时内容从露出的那 18px 里透出来；同时设置页目录也吸在 `top:0`，被工具栏压住。现在上内边距归工具栏自己（`.main { padding: 0 22px 28px }`），工具栏 `top: 0` 贴边、横向出血，目录吸在 54px 处（截图 `gui/qa/shots/final-settings.png`）。

同轮新增：

1. **Ctrl+K 快速跳转**（`CommandPalette.jsx` + `command-palette.js`）：页面（1–4）、设置五组、用量 20 个模块、服务商卡片、常用动作（刷新 / 切主题 / 编辑布局 / 显示隐藏悬浮窗 / 打开成就墙）。支持前缀优先的过滤（中文标签 + 拉丁关键词都能搜，例如输 `he` 命中"热力图"），↑↓ 选择、Enter 执行，跳转后滚到目标并高亮。工具栏放了入口按钮（窄窗口只留放大镜图标）。
2. **额度带行动建议**：最紧张那家进入 80%/耗尽时，头部会给一条数据驱动的建议——"可先用 Command Code GOAT（当前 9%）"，选的是全部实时配额卡里最闲的一家；纯函数 `pickQuotaAdvice` 有单测。额度带为空时给"还没有可用的额度数据 · 去连接"。
3. **成就点亮**：解锁 toast 的徽章改为弹簧放大入场 + 一次性光环脉冲（不循环，尊重减少动态）。

测试：前端 34 项通过（新增命令表过滤与建议逻辑）；真机截图 `gui/qa/shots/final-*.png`、`jump-*.png`、`advice-quota.png`。
