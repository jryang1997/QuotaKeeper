# 0002 聚焦只读额度与 Token 消耗

2026-10-15，用户授权收拢产品，优先展示 Token 消耗与订阅剩余额度。主界面保留订阅额度、Token 用量和设置；额度首屏直接显示本机今日、本周、本月 Token 摘要，用量历史在独立页按日期和采集源筛选。两类读数来源不同，保持分开，不能用本机 Token 估算套餐剩余额度。

这取代 ADR 0001 中继续保留成就和热力图等实验页面的方向。删除成就、分享图片、自由编辑模块和 CLI 升级管理；保留只读采集、数据诊断、额度和到期通知、托盘、悬浮窗，以及设置中的局域网只读展示。现有用户主题修改保留。以窗口名称猜周期的耗尽预测从桌面版移除，过期重置时间显示待刷新，避免把推测作为实时额度。

没有采用网关、模型配置和自动切换账号，也没有把全部历史分析塞进一个可展开总览。前者改变了只读边界，后者让同屏数据难以维持一致的筛选范围。研究与来源见[产品收口记录](../research/product-focus-2026-10-15.md)。
